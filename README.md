# 链路实验室

面向网安初学者的攻防因果教学沙盘：通过改变初始条件和防御措施，理解校园报名数据泄露路径为何成立或被阻断。

## 当前阶段

Day 1：需求冻结与访谈。应用尚未开发。

## 学习目标

1. 判断一条攻击路径继续推进需要哪些条件。
2. 解释阻断一条路径后，为什么仍可能存在另一条路径。
3. 区分“检测到请求”和“阻断了请求”。

## 模型边界

只建模一个虚构校园报名场景、两条预设路径、三种防御和两个初始条件。推演结果只适用于这些已建模路径，不代表真实系统的安全结论。不执行真实攻击。
