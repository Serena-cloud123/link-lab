# engine

确定性规则引擎。

## 职责

- 根据已冻结的场景配置、初始条件 O/T 和防御 D1/D2/D3，判定路径 A/B 是否成立。
- 输出带事件下标的确定性事件序列，供前端逐步播放。
- 每条结果附带规则依据和一句话解释模板。
- 不引入随机性、概率或模型推理。

## 本阶段范围

已实现路径 A（`evaluatePathA`）、路径 B（`evaluatePathB`）与运行组合（`evaluateRun`）。32 行期望 CSV 的 pathAReached、pathBReached、alertCount 三列均通过测试。

一句话解释模板、数据库落库与运行接口尚未实现。

## 非职责

- 不渲染画布、不播放动画。
- 不访问数据库、网络或模型 API。
- 不判断真实系统安全。
