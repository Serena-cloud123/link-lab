# 工作台低保真草图（Day 1）

布局草图，不规定颜色和精细样式。

| 区域 | 准备放什么 |
| --- | --- |
| 顶部 | 场景名称、A/B/C 预设、模型边界入口 |
| 左侧 | O/T 两档滑块、D1/D2/D3 防御选择、开始运行 |
| 中间 | 七节点关系图、路径流线、阻断护栏、告警标记 |
| 右侧 | 当前事件的条件、结果、一句话解释、残余路径 |
| 底部 | 上一步／下一步、事件位置、基线对比、关闭动画 |
| 完成后 | 三道题、保存记录、前往历史回放 |

操作顺序：选预设并预测 → 看基线 → 拖动条件或选择防御 → 重新运行 → 看流线与解释 → 答题 → 保存回放。

## 七节点在画布上的位置（初稿）

```
        [1 普通账号]
              |
        [2 报名应用]
          /        \
  [3 管理导出接口]  [4 诊断页面]
        |              |
        |         [5 服务令牌]
        |              |
        |         [6 数据服务]
          \        /
        [7 报名明细]
```

路径 A = 1→2→3→7；路径 B = 1→2→4→5→6→7。

护栏位置：3 与 7 之间为 D1 护栏；5 与 7 之间为 D2 护栏。被拒时流线停在护栏处并回弹，不穿透到 7。

告警位置：D3 的告警标记侧挂在 3 和 6 旁边，从实际到达的敏感接口发出侧向脉冲，不占主流线、不改变主流线成败。

## 访谈带来的布局约束

1. 三人均卡在"这一步为什么成立"，因此右侧解释栏与底部事件下标是主信息区，优先级高于任何装饰元素。关闭动画后这块必须完整可读。
2. 两位追问对象都强调"看懂之后要自己试、试的时候回头对照"。因此历史回放入口在草图中被提为独立区域（"完成后"一栏），而不是埋在页面角落。
3. O/T 滑块承担"改参数、才发现限制条件在哪"的作用，位置固定在左侧最上，与 D1/D2/D3 分开，避免把"条件"与"防御"混为一类操作。

## 尚未验证的部分

本草图未出示给任何受访者，布局可用性未经验证。下一轮需带着草图重问同一句话，否则布局只属于设计推断。
