## 失败与修复

1. 首次远程克隆失败：`fatal: unable to access ... Recv failure: Connection was reset`，24.5 秒。判为网络波动，重试成功，未改用本地克隆。不计入计时。
2. 删除复现目录报「正在使用中」：当前 PowerShell 窗口工作目录位于该目录内，且启动的 API 窗口未关闭。处理：先 `cd` 到别处、关闭残留窗口、按命令行匹配停止进程，再删除。
3. 重启 API 报 `EADDRINUSE: address already in use 127.0.0.1:3001`：上一轮用 `Stop-Process` 只杀了监听端口的子进程，外层 `node --watch` 立刻重新拉起。处理：同时停止占用端口的进程及其父 `node --watch` 进程，再启动。
4. 录屏工具问题：首遍使用 Win+G 只捕获活动窗口，命令行与浏览器均未进入画面，证据不足。改用整屏录制重录第二遍。
