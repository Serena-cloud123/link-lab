# 动画白名单（Day 1）

## 总规则

动画只能展示规则引擎已经给出的事件状态。前端按事件下标播放，不凭动画自行判断攻击成败。

| 引擎事件 | 允许出现的动画 | 关闭动画时必须保留的信息 |
| --- | --- | --- |
| 后续步骤未执行 | 该段流线消失 | “未执行”及原因 |
| 请求被拒绝 | 流线撞到对应权限护栏并回弹 | “请求被拒”、阻断节点及未满足条件 |
| 模拟数据到达 | 流线穿过终点 | “报名明细已到达（模拟）” |
| D3 产生告警 | 从敏感接口发出侧向脉冲，主流线不被拦截 | “检测到敏感请求，未自动阻断” |

## O/T 滑块

O/T 各只有两档，拖动时吸附到两档之一。拖动过程中只预览；松手且值发生变化时，才提交一次运行。松手没有变化就不提交。一次拖动最多产生一条新运行。

## 关闭动画

关闭动画或系统要求减少动态效果时，直接显示该事件下标的最终静态节点状态、边状态、事件文字和一句话解释。关闭动画不会隐藏条件或结果。

## 禁止的表现

背景粒子、无规则依据的闪烁、凭动画推测攻击概率、把 D3 告警画成阻断、未执行步骤提前出现成功流线。
