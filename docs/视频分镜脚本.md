## 一、时间轴

### 0:00—0:35 开场｜这是什么

- 画面：首页，从顶部四段说明缓慢下移，最后停在「全程虚构模拟数据」那行
- 素材：待录（首页实拍）
- 旁白要点：
  - 这是链路实验室，一套校园报名系统的安全演练沙盘
  - 给非安全专业的同学用，练的是判断力，不是攻防技术
  - 全程虚构数据，不接触任何真实系统
- 关键句（必须念到）：「像飞行模拟器之于飞行员——练错了不会影响任何真实数据。」

### 0:35—1:20 概念铺垫｜七个节点与两条路

- 画面：进入工作台，七节点图居中；鼠标依次划过 N1、N3、N4、N6、N7；切到预设下拉，展开路径 A 与路径 B
- 素材：待录
- 旁白要点：
  - 七个环节，从学生账号到报名明细
  - 两条攻击路径：短而直接的那条，和绕道诊断页借通行证的那条
  - 两个条件 O 和 T 分别卡在两条路上
- 字幕：路径 A：N1→N2→N3→N7；路径 B：N1→N2→N4→N5→N6→N7

### 1:20—1:42 演示一｜条件改变了什么

- 画面：调条件滑块，路径图实时变化
- 素材：`day15-sliders.mp4`（00:22，已有）
- 旁白要点：
  - 拖 O，路径 B 在诊断页断掉；拖 T，令牌取不到明细
  - 条件不改代码，改的是「这条路通不通」

### 1:42—2:23 演示二｜两条路的可视化对比

- 画面：切换预设，动画流线沿路径推进，两条路交替播放
- 素材：`day15-flow.mp4`（00:41，已有）
- 旁白要点：
  - 流线走到哪、停在哪，一眼能看出断点位置
  - 同条件下两条路的对比，是本产品的核心表达

### 2:23—3:41 演示三｜保存、回放与核对

- 画面：运行后保存 → 进入学习记录 → 打开只读回放 → 执行核对
- 素材：`day15-replay.mp4`（01:18，已有）
- 旁白要点：
  - 每次运行都能存下来，回放是只读的，不重新推演
  - 核对是零副作用的显式动作，不写库
  - 三题让你先预判，跑完再对照
- 关键句：「成败、告警、跳过的步骤，全部来自引擎或库里已存的记录，前端不重算。」

### 3:41—3:50 过渡

- 画面：切到编辑器，打开 `evidence/iterations/` 目录
- 素材：待录
- 旁白要点：下面是这个产品的开发过程，以及 AI 在其中扮演的角色

### 3:50—5:50 AI 协作复现（≥2 分钟，评分项）

- 画面：三段 Prompt 链的原始导出与整理稿对照；切到真实对话过程（时间轴可加速但不可剪断因果）；最后回到代码，指出某条 Prompt 对应的实际改动
- 素材：待录（必须真实录制，不可用截图拼接）
- 旁白要点：
  - 产品由三条 Prompt 链迭代而成，每条链的原始导出都存进了仓库
  - 举一个真实片段：需求怎么提、AI 怎么答、哪里出了偏差、人怎么纠
  - 说明意图对齐的做法：先冻结验收标准，再让 AI 实现
  - 说明工程掌控的做法：冻结文件、契约只增不删、AI 报告必须独立验证
- 关键句（必须念到）：「AI 的报告不能直接采信，要自己跑一遍、核对一遍。」
- 可选加分：展示一次真实 Bug（动画层被 CSS 解析为子代组合符导致整体失效），说明如何定位

### 5:50—6:20 收尾｜学习记录与预判对照

- 画面：学习记录页，三题的预判与实际结果并排
- 素材：待录
- 旁白要点：
  - 学完能回答三个问题：哪条路通、哪个防御有效、告警和阻断的区别
  - 记录可回看，方便课堂复盘
- 关键句：「告警不等于阻断——这是这个沙盘最想让人记住的一句话。」

### 6:20—6:40 片尾

- 画面：首页，回到四段说明，静止 3 秒
- 素材：待录
- 旁白要点：链接实验室，虚构场景，仅作教学演示
