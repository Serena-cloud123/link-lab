## 修改方案

### 文件 1：`apps/web/src/App.tsx`

**1.1 抽出统一解析函数（系统偏好无条件优先）**

新增两个纯函数（放在组件外，便于 `useState` 初始化器和 `matchMedia` 回调共用同一套逻辑）：

```ts
function systemPrefersReducedMotion(): boolean {
  try {
    return window.matchMedia("(prefers-reduced-motion: reduce)").matches;
  } catch {
    return false;
  }
}

function resolveAnimationsEnabled(): boolean {
  // 系统偏好无条件优先：要求 reduce 时一律关闭，忽略 localStorage
  if (systemPrefersReducedMotion()) return false;
  let stored: string | null = null;
  try {
    stored = window.localStorage.getItem("animationsEnabled");
  } catch {
    stored = null;
  }
  if (stored === "true") return true;
  if (stored === "false") return false;
  return true; // 无持久化记录时默认开启
}
```

**1.2 初始化器改用 `resolveAnimationsEnabled`**

```ts
const [animationsEnabled, setAnimationsEnabled] =
  useState<boolean>(resolveAnimationsEnabled);
```

**1.3 新增 `systemReducesMotion` state，供禁用开关按钮**

```ts
const [systemReducesMotion, setSystemReducesMotion] =
  useState<boolean>(systemPrefersReducedMotion);
```

**1.4 `matchMedia` change 回调复用同一逻辑**

在现有 `useEffect` 的 handler 中，把
```ts
if (matches) setAnimationsEnabled(false);
```
改为
```ts
setSystemReducesMotion(matches);
setAnimationsEnabled(resolveAnimationsEnabled());
```
保证系统偏好变化时不会退化为只看 localStorage。

**1.5 `toggleAnimations` 守卫系统 reduce**

```ts
function toggleAnimations() {
  if (systemPrefersReducedMotion()) return; // 系统 reduce 期间不允许手动开启
  setAnimationsEnabled((prev) => {
    const next = !prev;
    try {
      window.localStorage.setItem("animationsEnabled", next ? "true" : "false");
    } catch { /* 隐私模式静默忽略 */ }
    return next;
  });
}
```

**1.6 向 `PlaybackBar` 传 `animationsToggleDisabled={systemReducesMotion}`**

四个 `PlaybackBar` 调用处（工作台 1 处 + 记录页 2 处）统一追加该 prop。

> 选择理由：系统 reduce 期间把开关按钮置灰禁用，用户能直观看到「动效关」且无法误点开启；`toggleAnimations` 内部再加一道守卫作双保险。localStorage 写入逻辑在系统不 reduce 时保持原样，用户偏好仍被持久化，系统 reduce 解除后会自动恢复。

### 文件 3：`apps/web/src/styles.css`

在文件末尾追加 `@media (prefers-reduced-motion: reduce)` 兜底块。

**纯动画类名清单（仅运动、不含静态信息，纳入兜底）：**

| 类名 | 判断依据 |
| --- | --- |
| `.flow-overlay-path`（及 `-passed`/`-data-arrived`/`-rejected` 变体） | 自定义边里的 overlay `<path>`，只负责流线运动；静态边色/虚线在 `.graph-edge-active.graph-edge-*` 上，是不同元素 |
| `.alert-pulse-overlay` | D3 侧向脉冲圆点，纯运动；静态 ⚠ 徽标在 `.graph-node-alert-badge` 上 |
| `.arrived-pulse-overlay::before` | N7 到达脉冲，纯运动；静态「已到达」徽标在 `.graph-node-arrived-badge` 上 |

**含静态信息、不动的类：** `.graph-edge-active.graph-edge-*`（边色/虚线）、`.graph-node-alert`/`.graph-node-alert-badge`（告警徽标）、`.graph-node-arrived`/`.graph-node-arrived-badge`（到达徽标）、`.event-outcome.*`/`.event-rejected`/`.event-skipped`/`.event-arrived`/`.event-alert`（事件文字）、`.condition-checks`/`.unmet-reasons`（条件理由）。

```css
@media (prefers-reduced-motion: reduce) {
  .flow-overlay-path,
  .alert-pulse-overlay,
  .arrived-pulse-overlay::before {
    animation: none !important;
    opacity: 0 !important;
  }
}
```

此兜底不依赖 JS 类名，即使 JS 判错也能杀死运动；静态边色、徽标、文字完全不受影响。
